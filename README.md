# 🕹️ Tic-Tac-Toe Web Game

A clean, interactive, and responsive Tic-Tac-Toe game built using **Vanilla JavaScript**, **HTML5**, and **CSS3**. This project focuses on clean DOM manipulation and efficient game logic.

---

## 🚀 Live Demo
(https://daksh-dhasmana.github.io/Project-Tic-Tac-Toe/)

## ✨ Features
* **Two-Player Mode:** Play locally with a friend.
* **Smart Win Detection:** Instantly calculates winning combinations (rows, columns, and diagonals).
* **Draw Logic:** Detects when the board is full and no moves are left.
* **Restart Functionality:** A dedicated button to reset the state without refreshing the page.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for the game grid.
* **CSS3:** Custom styling using Flexbox/Grid for a modern look.
* **JavaScript (ES6):** Handles the core game engine, turn management, and UI updates.

## 📂 Project Structure
* `index.html` - The skeleton of the application.
* `style.css` - Visual styling and layout.
* `script.js` - Game logic, win checking, and event handling.
